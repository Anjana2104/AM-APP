# EAM Application — User Manual

**Engagement & Account Management (EAM)**  
Version 1.0 | June 2026 | Rockwell Automation — Internal Use Only

---

## About This Manual

This user manual provides step-by-step instructions for all screens and features of the EAM application. It is intended for account managers, engagement leads, and administrators.

## System Requirements

| Item | Requirement |
|------|-------------|
| Browser | Google Chrome 115+, Microsoft Edge 115+, Firefox 112+ (Chrome recommended) |
| Resolution | 1280 × 720 minimum; 1920 × 1080 recommended |
| Network | Internal network or VPN required |

## Quick Reference

### Export PDF — Where Available

| Module | Location |
|--------|----------|
| Finance Summary | PDF icon — top right of Finance Summary tab |
| Internal Process | PDF icon — top right of SOW Detail View |
| Client Requests | PDF icon — top right of Insights tab |
| Resource Intelligence | Red PDF icon beside Refresh on resource detail panel |

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Esc` | Close any open drawer or detail panel |
| `Ctrl + F` | Browser-native search within current table |
| `Browser Back` | Return to previous page, preserving all filters and state |

### Glossary

| Term | Meaning |
|------|---------|
| SOW | Statement of Work — defines scope, deliverables, and timeline |
| PIW | Project Initiation Workbook — Excel file with resource and milestone data |
| RA ID | Rockwell Automation Employee ID |
| Beeline ID | Client staffing system request identifier |
| Eprev | E-Prevailing — contract type indicator |
| PROMS ID | Project Management Office system identifier |
| Audit Log | Immutable field-level change history — who changed what, and when |
